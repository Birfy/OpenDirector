# 画布学习工程

访问 `/ai-tool/ai-canvas`，或从首页点击“画布”。项目菜单中的“打开示例画布”提供独立的示例项目，拖入本地素材可继续编辑。

## 依据与边界

原站画布是独立 `octo_web` 应用；首页发布包不能代表画布。最初采集的 15 个 JS、3 个 CSS，以及本轮补充的 23 个功能 JS，均保存原始 URL、长度和 SHA-256，见 [画布资源](../research/canvas/README.md) 和 [功能资源分析](../research/canvas/features/README.md)。格式化发布包不是发布前的 TypeScript 工程。

本轮还通过登录界面实际测试图片、视频、配音、音乐和后处理，见 [AI 实测记录](AI-LIVE-TESTS.md)。该记录区分实际完成、已提交待核对和未执行；折扣与价格不作为长期保证。

`src/canvas/` 是独立编写的 React + TypeScript 工程，使用 React Flow 12 和 Three.js。它不执行原站脚本。持久化格式、3D 场景与任务草稿是本地学习工程的模型，不是即梦私有协议。

## AI 任务的真实状态

画布没有连接即梦生成服务。生成面板的“准备生成任务”打开请求说明，可导出草稿、打开原站或导入真实结果；不会运行 900ms 计时器后伪装生成成功。导入结果按真实文件类型校验，新增媒体节点并连接来源；项目切换、来源删除或素材改变后，不把迟到结果写入错误位置。

高级 AI 工具没有适配器时明确显示未连接。静态分析只找到入口、但未确认参数协议的工具不能提交任务。工具栏的存在不等于生成服务已恢复。原站账号、积分、上传、云项目、云协作、AI 助手与私有接口没有接入；Cookie 或浏览器登录数据不进入工程。

首页保留带明确标识的本地演示模式；它和画布的真实结果导入是两个流程。

## 代码入口

| 文件 | 职责 |
|---|---|
| `CanvasWorkspace.tsx` | 工作区、React Flow 适配、面板、键盘、导入导出和编辑来源归属 |
| `CanvasNodeView.tsx` / `NodeComposer.tsx` | 节点卡片、端口、参数、参考与首尾帧 UI |
| `generationCatalog.ts` / `toolCatalog.ts` | 模型/工具配置、观察证据、参数约束和任务草稿 |
| `model.ts` / `dataBoundary.ts` | 文档命令；新域的统一解析、复制、等值比较与引用映射 |
| `history.ts` / `operations.ts` | 内容历史、拖拽事务、编组、堆叠和完整子图复制 |
| `storage.ts` / `linkedResults.ts` | 持久化验证、IndexedDB、来源绑定与关联结果 |
| `ImageEditor.tsx` / `LayerBoard.tsx` | 像素编辑、手工图层文档与 Canvas2D 合成 |
| `LocalImageTools.tsx` / `LocalMediaEditor.tsx` | 标注、蒙版、拆图、视频帧、媒体裁剪与音轨处理 |
| `TimelineEditor.tsx` / `timeline.ts` | 真实媒体时间线、播放头、源出入点与编辑操作 |
| `SubjectEditor.tsx` / `StackEditor.tsx` / `ToolEditor.tsx` | 主体、堆叠、参数工具的独立编辑器 |
| `DirectorStage.tsx` / `stageDocument.ts` | Three.js 预演与独立场景格式 |

素材转换为可恢复的 data URL 后写入 IndexedDB。导出的画布 JSON 包含媒体、图层、时间线与场景数据。`localStorage` 仅记录最近项目；存储容量以浏览器为准，保存失败会显示。清除网站数据会删除本地项目，应先导出备份。

## 常用操作

- 空格＋拖动：平移；H 切换抓手、V 切换选择工具。平移可从节点上开始，不改变节点位置；⌘/Ctrl＋滚动：缩放。
- 空白处拖动：框选；Shift/⌘/Ctrl＋点击：多选。
- V / H / T：选择、抓手、文本。
- ⌘/Ctrl C / V / D：复制、粘贴、复制副本。
- ⌘/Ctrl G / Shift G：编组、取消编组。
- ⌘/Ctrl Z / Shift Z：撤销、重做。
- Shift 1 / 2：适应内容、适应选区。
- Delete / Backspace：删除节点或选中连线。

实际运行的检查与浏览器验收范围见 [验证记录](VALIDATION.md)。
