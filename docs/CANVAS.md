# 画布学习工程

访问 `/ai-tool/ai-canvas`，或从首页点击“画布”。项目菜单中的“打开示例画布”会创建一个独立项目，内含文本、原创插画、视频占位节点和参考连线。拖入本地素材即可继续编辑。

## 依据与边界

2026-10-26 实际打开原站画布后，确认它是独立 `octo_web` 应用；首页的 `dreamina` 发布包不能代表画布。补采的 15 个 JS、3 个 CSS，以及原始 URL、长度和 SHA-256 在 [research/canvas](../research/canvas/README.md)。格式化代码在该目录的 `readable/`，没有原始 TSX 或 source map。

实际界面观察包括：全屏深色点阵画布、左侧创作栏、底部导航、节点左右端口、节点标题、图片生成器、相机/配色/风格及比例/分辨率/数量选项。静态代码确认 React Flow、8%–800% 缩放、引用边和编辑来源边、多种节点以及撤销命令栈。具体原始文件和行号见采集报告。

`src/canvas/` 是依据这些证据独立编写的 React + TypeScript 实现，使用 React Flow 12。它不加载采集到的站点脚本，也不把格式化发布包声称为原始工程。我们的 node/edge 数据模型是为本地重建设计的，未冒充原站协议。

## 可用功能

| 区域 | 已实现行为 |
|---|---|
| 工作区 | 独立全屏路由、点阵背景、拖拽平移、滚轮平移、修饰键缩放、抓手、框选、小地图、连线开关、适应内容/选区 |
| 节点 | 文本、图片、视频、音频、文件、分组；改名、移动、尺寸调整、锁定、前后层级、自动排列、删除 |
| 引用关系 | 拖动端口建立连接，端口点击创建关联节点；禁止自连接和重复连接；删除节点清理相关边 |
| 编辑历史 | 撤销/重做，拖动与尺寸调整合并为一个步骤，移动视口不占用历史；复制整组重映射节点和内部边 |
| 素材 | 文件选择、拖入、粘贴图片；实际图像预览、视频/音频播放；本地素材引用、下载、全屏预览 |
| 图片编辑 | 比例裁剪、裁剪缩放/位置、90°旋转、双向翻转、亮度/对比度/饱和度，实际生成 PNG 并支持撤销 |
| 生成面板 | 模型、画幅、数量、分辨率、视频时长、提示词、参考节点、相机/配色/风格；本地示意预览和取消 |
| 项目 | IndexedDB 自动保存、项目列表、新建/打开、JSON 导入/导出、节点搜索；保存失败阻止切换 |
| 创作辅助 | 镜头语言填入、三镜头模板；按多行描述创建参考链的本地编排助手 |

AI 生成、抠图/扩图/消除笔、对话模型、云分享、账号/额度和远程资产未接入。预览按钮产生原创矢量示意图；视频/音频只演示任务状态，并支持导入现有媒体播放。参数选择用于研究界面与状态流转，不代表调用了模型或按 4K 渲染。

原站的时间线节点、主体节点、堆叠节点、导演台、图层板和完整高级编辑面板尚未复现。当前成果是可操作的核心画布重建，不是完整原站所有功能的完成声明；补采清单仍有 228 个未下载的动态资源。

## 代码入口

| 文件 | 职责 |
|---|---|
| `CanvasWorkspace.tsx` | 路由内工作区、React Flow 适配、面板、键盘、导入导出与任务生命周期 |
| `CanvasNodeView.tsx` / `NodeComposer.tsx` | 节点显示、连接端口、尺寸控件、生成参数和引用 UI |
| `model.ts` | 文档、节点、边与命令；锁定、删除和层级语义 |
| `history.ts` | 内容历史和拖拽事务；视口与编辑历史分离 |
| `geometry.ts` / `operations.ts` | 嵌套坐标、排列、编组、完整子图复制和重映射 |
| `storage.ts` | JSON 边界验证、IndexedDB 事务、错误返回；拒绝不可恢复的 blob URL |
| `previewResult.ts` | 校验预览所属项目/节点，只把有效结果合入当前文档 |
| `ImageEditor.tsx` | 浏览器 Canvas2D 实际像素编辑；不执行原站编辑算法 |
| `assets.ts` | 本工程绘制的 SVG、示例项目和文件读取/下载 |

节点显示状态和 React Flow 测量值不进入持久化文档。上传内容转换为可恢复的 data URL 后写入 IndexedDB；没有人工设置 5MB localStorage 限额，最终容量由浏览器存储决定，错误会显示在保存状态。`localStorage` 只记录最近项目 ID。JSON 导出包含媒体内容，可以在另一浏览器导入为独立项目。

## 常用操作

- 空格＋拖动：平移；⌘/Ctrl＋滚动：缩放。
- 空白处拖动：框选；Shift/⌘/Ctrl＋点击：多选。
- V / H / T：选择、抓手、文本。
- ⌘/Ctrl C / V / D：复制、粘贴、复制副本。
- ⌘/Ctrl G / Shift G：编组、取消编组。
- ⌘/Ctrl Z / Shift Z：撤销、重做。
- Shift 1 / 2：适应内容、适应选区。
- Delete / Backspace：删除节点或选中连线。

清除浏览器网站数据会删除本地项目，使用“导出画布”保存备份。浏览器实测和自动化测试范围见 [验证记录](VALIDATION.md)。
