# 画布学习工程

访问根地址或 `/ai-tool/ai-canvas` 即可进入画布。左上角星形按钮打开本地项目列表。项目菜单中的“打开示例画布”提供独立的示例项目，拖入本地素材可继续编辑。

## 依据与边界

原站画布是独立 `octo_web` 应用；首页发布包不能代表画布。最初采集的 15 个 JS、3 个 CSS，以及本轮补充的 23 个功能 JS，均保存原始 URL、长度和 SHA-256，见 [画布资源](../research/canvas/README.md) 和 [功能资源分析](../research/canvas/features/README.md)。格式化发布包不是发布前的 TypeScript 工程。

本轮还通过登录界面实际测试图片、视频、配音、音乐和后处理，见 [AI 实测记录](AI-LIVE-TESTS.md)。该记录区分实际完成、已提交待核对和未执行；折扣与价格不作为长期保证。

`src/canvas/` 是独立编写的 React + TypeScript 工程，使用 React Flow 12 和 Three.js。它不执行原站脚本。持久化格式、3D 场景与任务草稿是本地学习工程的模型，不是即梦私有协议。

## AI 任务的真实状态

画布没有连接即梦生成服务。生成面板的“准备生成任务”打开请求说明，可导出草稿、打开原站或导入真实结果；不会运行 900ms 计时器后伪装生成成功。导入结果按真实文件类型校验，新增媒体节点并连接来源；项目切换、来源删除或素材改变后，不把迟到结果写入错误位置。

在生成面板中选择“本地服务”分组的模型时，任务经由本地 API（`apps/api`）提交给“模型接入”中配置的服务。`src/backend/rules.ts` 按该模型的输入规则校验参考类型、数量、视频模式和时长；`generation.ts` 把参考上传为本地 API 项目的当前素材，每次提交使用新的生成节点，轮询任务并下载结果，再走与导入相同的来源绑定写回画布。迟到或画布切换后的结果保存在本地 API 项目中，由 `sync.ts` 在打开画布或手动同步时加入。H3 接续引用同一服务生成的视频：相同文件按 SHA-256 指纹复用原结果素材，后端据此找到原任务的服务端任务号。

“与 AI 对话”在接入对话 Agent 后改用本地 API 的助手（`AssistantPanel`），未接入时保留按行创建图片节点的本地编排。

在当前页面通过节点提交的图片、视频和音频任务，会在来源节点内显示生成遮罩：排队时缓慢渐变，生成中显示流动色域、星点与扫光，已有素材保留在毛玻璃后。状态文字来自真实任务阶段，不显示估算百分比；批量任务剩余数量随完成而减少，最后一个任务结束、失败或取消后移除遮罩。动画独立于选中状态，不阻挡节点拖动和连线，也不进入保存数据或撤销历史。新生成及同步回来的媒体结果短暂淡入；系统开启“减少动态效果”时显示静态状态。效果是本工程的独立实现，不是原站动画代码的完整恢复，见 [预览](generation-animation.png)。

高级 AI 工具没有适配器时明确显示未连接。静态分析只找到入口、但未确认参数协议的工具不能提交任务。工具栏的存在不等于生成服务已恢复。原站账号、积分、上传、云项目、云协作、原站 AI 助手与私有接口没有接入；Cookie 或浏览器登录数据不进入工程。

首页和模拟生成任务已移除。原始首页资源仍保留在研究目录中，不参与应用运行。

## 常用操作

- 空格＋拖动：平移；H 切换抓手、V 切换选择工具。平移可从节点上开始，不改变节点位置；⌘/Ctrl＋滚动：缩放。
- 空白处拖动：框选；Shift/⌘/Ctrl＋点击：多选。
- 单击节点选择，双击定位；空白双击打开新建菜单，抓手模式不触发。文本节点先选中，再点击、双击或按 Enter 进入文字编辑，Escape 退出编辑。
- 拖动时靠近节点边缘或中心：吸附并显示辅助线；⌘/Ctrl 暂时绕过。更多菜单可切换点阵、对象吸附和网格吸附，多选工具栏提供对齐与分布。
- 从端口拖到空白处：保留预览线并选择关联节点类型；Esc 或点击空白取消。
- V / H / T：选择、抓手、文本。
- ⌘/Ctrl C / V / D：复制、粘贴、复制副本。
- ⌘/Ctrl G / Shift G：编组、取消编组。
- ⌘/Ctrl Z / Shift Z：撤销、重做。
- Shift 1 / 2：适应内容、适应选区。
- Delete / Backspace：删除节点或选中连线。
