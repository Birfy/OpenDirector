# 旧运行链路清理记录

日期：2026-10-29。对应 [实施计划 P00](../OPENDESIGN_REFACTOR_COMMIT_PLAN.md)。本次将共享服务解耦、Agent 收缩和旧服务删除合并为一个 Git commit。

## 实际变更

- 删除 24 个旧 API 路由：旧分镜板、分镜驱动时间线、旧后端成片导出、旧制作计划、制作聊天、步骤审阅和反馈。
- 删除 13 个专属运行模块及相应请求/领域字段，不再启动旧制作与导出后台服务。
- 单素材生成和结果采用不再查询分镜或制作计划，保留画布输入、参考内容及模型配置变化保护。
- Agent 只开放项目读取、文本读取、文本保存、素材生成和任务查询五项工具；任务摘要提取到独立模块，不再依赖旧制作工具。
- 素材依赖、版本查询与项目重命名不再读取旧分镜、计划或导出文件，继续保护有效的画布、素材、聊天、历史、任务和会话关系。
- 按用户要求直接删除 12 个专属旧功能测试模块；混合测试文件中的旧业务用例一并移除，通用测试改用独立画布生成夹具。
- README、助手文案、架构说明和实施计划同步更新。

## 保留范围

OpenDesign 的画布、页面布局、高级编辑器、浏览器时间线、MP4/FCPXML/素材包导出继续保留。模型配置、能力声明、参数和输入校验、协议适配、排队、取消、原任务恢复及 FastH3 部署工具保留。

本次不实施新统一存储，不迁移、不清空已有工程或模型凭证。旧后端分镜/制作/导出 API 和 Agent 工具直接退役，不提供兼容入口。尚未移除的 Python、Node 依赖仍被保留能力或研究工具使用，本次没有通过删除共享第三方包来缩减功能。

## 验证

当前工作区复用相邻 OpenDesign 的 Python 虚拟环境，并将相同的前端依赖复制到当前工作区的忽略目录中；Python 导入路径显式指向本仓库，避免测到相邻仓库代码。生成请求使用测试替身，没有调用真实模型或部署远端服务。

```sh
PYTHONPATH="$PWD/packages/core/src:$PWD/apps/api/src" ../OpenDesign/.venv/bin/python -m pytest tests -q --tb=short
npm test
npm run build
git diff --check
```

结果：Python 504 项通过；Node 测试入口报告 34 项通过；TypeScript 检查和 Vite 生产构建通过；差异空白检查通过。

后端测试覆盖实际服务启动、旧端点不存在、活动工具集合、已退役文件不再阻断画布/素材/历史/重命名、在途生成仍阻止重命名、供应商错误保存及脱敏，以及保留的模型、排队、恢复、画布和历史行为。

前端测试覆盖现有画布、编辑边界与时间线等逻辑；构建保留高级编辑器和时间线依赖。此次没有执行浏览器视觉验收或真实模型端到端实测，不以单元测试和构建成功替代这些验证。

环境说明：沙箱内连空 FastAPI TestClient 都会挂起，使用沙箱外的本地测试执行完成验证。测试报告一项 FastAPI/Starlette 的 httpx 弃用警告；Vite 报告现有大体积 chunk 警告，两者均未阻止检查通过。测试使用 Node 24.14.0，仓库声明的推荐安装版本仍为 24.22.1 或更新版本。
