# 画布交互对照（2026-10-27）

本轮在已登录 Brave 的独立测试项目中操作原站，再修改本地 React 工程。没有提交 AI 生成任务或消耗积分，没有改动此前的原站素材研究项目。本地浏览器验收使用 `localhost:5173` 的独立存储，与原有 `127.0.0.1:5173` 项目隔离。

## 观察、依据与实现

| 项目 | 原站依据 | 本地修改 |
|---|---|---|
| 新建节点 | 实际创建图片会显示底部生成器；创建时间线、主体只放置卡片，不打开编辑器 | 保留媒体生成器；时间线、主体、导演台改为显式点击卡片编辑入口；空媒体节点的主体可选择/拖动，上传使用独立按钮 |
| 空白处释放连线 | 实际拖动图片输出端到空白处：蓝色预览线保留，出现添加节点菜单，节点/边计数仍为 1/0；选择视频后变成 2/1 | `Menu` 持有临时端点，视口内显示贝塞尔线；选择类型后在端点创建节点并添加边，一次撤销恢复；Esc 或点击空白取消 |
| 背景点阵 | 原站截图可见灰色点阵；发布包网格大小为 18 | 提高对比度，18 世界坐标间距，缩小时分级抽稀；更多菜单可关闭 |
| 对齐吸附 | 发布包默认对象吸附开启，进入阈值 5 屏幕像素、释放阈值 8、Cmd/Ctrl 可绕过；网格吸附默认关闭 | 对节点边缘/中心及多选整体边界吸附，显示横纵虚线；保持分组相对坐标与继承锁定；支持可选网格吸附及对齐/等间距菜单 |
| 参考线动效 | 实际截图中，选择相关节点后参考线变蓝并出现亮色光段，其他线为灰色 | 选中、悬停及目标生成时显示移动光带；生成中加快；系统减少动态效果时保留静态线 |

原站吸附参数和辅助线样式来自已保存的发布包，未声称在原站拖动中逐帧捕获了辅助线：

- `research/canvas/readable/js/9d08566a14ad-canvas-view.c799ffc841.js`：约 26300 行，`canvas-snap-guide-x/y`；约 30593 行，网格吸附默认关闭；约 31600 行，修饰键处理。

## 同时修复的交互问题

- 移除新建时间线、主体和导演台的自动全屏编辑器。
- 新节点使用实际宽高定位；关联节点的端口位于释放点。按生成器的实际占用区域调整视口，避免节点被面板遮挡或出现在屏幕外。
- XYFlow 12.12 的非零起拖阈值在首次移动事件才记录指针偏移，快速起拖会丢掉第一段距离。本地设为从按下时记录，并保留 4 像素的点击容差；无内容变化不产生历史。
- 快捷键由画布根容器在捕获阶段处理，移除重复的方向键逻辑。Esc 不再被节点的默认键盘选择行为干扰；输入框继续处理自己的文本快捷键。
- 修饰键多选直接使用本次点击事件和按下前的选区，避免焦点变化/快捷键状态不同步时丢失旧选择。
- 工作区使用 `overflow: clip`，防止聚焦隐藏上传控件或控件自动滚动时让整个固定画布偏移。内部面板各自保留滚动。
- 锁定节点及锁定分组后代禁用连接端口；持久化继续使用已有的节点/边校验。

## 实际验收

- 图片输出拖到空白处，菜单打开且预览线保留；选视频后新增一个节点和一条边，单步撤销/重做正确。
- 既有图片之间直接连接成功；Esc 取消待连线后仍为原有 3 节点/1 边，无额外数据。
- 分组内空白处也能保留待连线；创建的视频归属该分组。真实导出文件经生产 `parseDocument` 校验通过（5 节点、2 连线），新节点保存父组 ID 和相对坐标。
- 空图片主体实际可拖动；原始目标 X=596 自动吸附到 X=600。拖动中读取到 X=600 和 Y=150 的两条真实辅助线，结束后均清除。
- 三个节点框选、顶对齐、撤销成功。组移动 `(30,30)` 时父节点和每个子节点都只移动一次，单步撤销恢复；右箭头只移动 1 像素，快捷键撤销恢复。
- 全选、Shift 点击多选、Esc 清除选区经过实际点验。时间线/主体/导演台创建后模态对话框数量均为 0。
- 连线光带的 `stroke-dashoffset` 在两次读取间从约 757 变为 714，确实在动画；背景点阵、菜单和明确上传入口可见。
- 测试期间发现工作区 `scrollTop=22`；修复后为 0，顶部栏恢复完整。
- 刷新后分组、子节点和已有连线恢复；关闭背景点阵时背景 SVG 移除，重新打开恢复显示。
- 六项自动回归覆盖缩放阈值、中心/边缘吸附、迟滞释放、修饰键绕过、可选网格、锁定祖先、父子/多选位置、对齐分布及历史恢复。

这些是独立实现与针对性验收，不是原站全部前端已恢复的声明。未覆盖原站全部节点组合、触屏/多指、所有浏览器、等距拖动提示、缩放手柄的吸附、原站每一帧的动画曲线；系统减少动态效果的样式经源码检查，本轮未修改系统设置。生成服务接入范围仍见 [CANVAS.md](CANVAS.md)。
