# 工程导读

## 运行应用

```text
main.tsx
  └── App.tsx
      └── CanvasWorkspace  懒加载的全屏编辑器
          ├── model / hierarchy / history   命令、分组继承与撤销重做
          ├── storage                      IndexedDB 与 JSON 边界
          ├── CanvasNodeView               节点交互
          └── 各类编辑器                    图片、图层、时间线、导演台等
```

根地址和旧首页地址都直接打开画布。工作区从 URL 或最近项目标记恢复文档，并更新为项目的规范地址。左上角按钮打开本地项目列表；新建、切换和 JSON 导入共用保存与切换流程，切换期间暂停输入，保存失败保留当前项目。原首页组件、样例列表、模拟生成任务及专属样式已经移除；`research/`、`recovered/` 和快照语义研究仍保留。

## 本地服务的当前边界

FastAPI 只装配项目、模型与通用设置、素材、画布、助手和独立生成任务。生成任务生命周期保留启动恢复、排队、取消、继续查询与结果落盘；结果采用只核对画布输入、参考内容和模型配置。

MuseShow 旧分镜板、分镜驱动时间线、后端成片导出、旧制作计划及其制作聊天、审阅和返修链路已移除，相关 API 和 Agent 工具不再注册。历史版本、素材删除保护和项目重命名不再读取这些旧业务文件；仍然检查有效的画布、聊天、素材、任务、历史与会话依赖。旧文件不会被本次清理自动删除。

OpenDesign 的 `TimelineEditor`、浏览器 MP4 合成、FCPXML/素材包导出及全部高级编辑器继续保留。画布仍以 IndexedDB 保存，后端项目仍用于生成与助手；统一存储与新业务对象属于后续重构，见根目录的需求和实施计划。

## 画布编辑器

`CanvasWorkspace` 拥有当前项目、选择、面板与编辑来源；`model` 拥有命令语义。`dataBoundary` 统一解析、复制和比较时间线、主体、堆叠、工具、图层和场景，不由历史或存储重复解释。媒体快照和节点引用分开保存：删除来源节点不会销毁已进入时间线或主体的素材。复制只重映射复制范围内的身份。

`hierarchy` 统一计算分组祖先与继承锁定，供命令、几何和 UI 使用。锁定分组不改写子节点的显式锁定标记。`model` 在更换素材时清除旧像素对应的图层、工具草稿和元数据；新的图层输出可以通过同一条命令原子写入。

`LayerBoard` 使用 Canvas2D 合成，`TimelineEditor` 控制真实媒体元素，`DirectorStage` 使用 Three.js。它们提交结构化数据或真实像素结果，由工作区按来源归属写入历史。`linkedResults` 为像素操作和结果文件导入保留来源连线；操作途中项目切换、来源删除或媒体替换会拒绝写回。

`generationCatalog` 区分菜单观察、已验证配置和未知组合；`toolCatalog` 区分本地编辑与待接入服务。画布没有默认模拟生成。任务草稿可导出，原站结果可作为真实媒体导入；要接入自己的服务，应在适配器中实现能力发现、报价、提交、取消与结果检查。账号 Cookie 和原站私有请求重放不属于该设计。

## 可以从哪里开始修改

1. 从 `canvas/model.ts`、`history.ts` 和对应测试理解命令、事务和撤销。
2. 阅读 `canvas/dataBoundary.ts`、`storage.ts` 理解项目导入与保存的校验边界。
3. 从各编辑器追踪结构化数据或媒体结果如何写回节点。
4. 对照 `domain/bannerSnapshot.ts` 与恢复模块 `TJ` 研究快照校验；原首页材料属于研究输入，不再是运行应用。
5. 连接自己的模型服务时，在任务适配器边界设计 API，见画布导读中的服务接入说明。

## 版本与验证的含义

本学习工程选用 React 19、Vite 6 与 TypeScript 5，并将实际版本写入 lockfile。它们是重建工程的依赖，不能据此推断即梦原始 package.json。已采集发布包中存在 ReactDOM 18.2 相关标记，但这也不足以精确重建原项目完整依赖锁定。

`npm test` 覆盖快照校验、画布结构/历史/存储边界、异步预览结果归属与媒体处理取消；`npm run build` 验证重建工程的类型与打包；`npm run recovery:check` 核验恢复材料的字节、范围、语法和静态依赖。三者分别回答不同问题。恢复模块通过静态检查，不代表原站应用可以完整运行。
