# 独立本地创作功能

以下功能由学习工程自行实现，不使用即梦登录、积分、私有接口或云渲染服务。

## 时间线合成 MP4

打开时间线，加入图片、视频和音频，设置源入出点、倍速、音量及音轨起点，点击 **合成 MP4**。完成后可下载，也可将实际视频加入画布；加入画布后编辑器保持打开，点击 **应用编辑** 保存时间线修改。

画面片段可拖动重排；音频可拖动调整起点，或移到其他音轨，松开时按项目帧率对齐。音频属性里的左右按钮逐帧微调。同轨重叠、不同类型轨道及轨道外落点会拒绝变更；拖动中按 Esc 取消。每次拖动只记一次历史，轨道区域支持 ⌘/Ctrl+Z 撤销、⌘/Ctrl+Shift+Z 或 Ctrl+Y 重做。

- 画面顺序沿用时间线规则，等比适配并补黑边。音轨超过视觉轨时输出黑色画面。
- 支持多条音轨叠加、源视频声音、片段/轨道静音、音量与显式起点。倍速会改变音调，预览与导出使用同一规则。
- 720p、1080p、横竖画幅和方形预设；JSON 导入的其他尺寸原样显示。H.264 输出要求偶数宽高。
- 使用 WebCodecs 和 [Mediabunny](https://mediabunny.dev/guide/writing-media-files) 编码 H.264 + AAC，依赖按需加载。无需安装 FFmpeg；缺少所需编码能力时显示错误，不把 WebM 改名为 MP4。
- 音频按一秒分块混合，视频按时间线帧率逐帧读取并编码。源文件和最终压缩文件仍留在内存，超长/超大项目尚未做压力测试。
- **取消合成**或关闭编辑器会停止任务并释放解码器、编码器和临时图片。成功前不会插入结果节点。
- AAC 编码可能带来起始延迟和尾部填充。当前 macOS 浏览器实测 7.500 秒视觉轨的 MP4 容器时长为 7.573 秒。加入画布时重新读取输出文件的实际尺寸和时长；不宣称采样级音画同步。

## 人物动作与导演预演

导演台的本地人物由髋、膝、肩、肘关节组成，提供站立、行走、跑步和挥手动作，可以调整动作速度、幅度和人物颜色。动作按时间采样，与主体位移及镜头关键帧叠加；即使没有关键帧，也能播放动作。

**合成预演 MP4** 输出 1280×720、30 fps、无声的实际 WebGL 画面，可下载或加入画布。合成使用独立渲染器，不包含选中主体的高亮。动作设置随舞台 JSON 和画布项目保存，旧舞台没有动作字段时保持站立。

这是原创关节人偶预演，尚不支持导入 FBX/GLB 蒙皮角色、动画重定向或角色资产商城。

## 跨项目素材复用

左侧 **资产库 → 其他项目的素材**，选择本机已保存项目，可按名称搜索、按图片/视频/音频/文件筛选，再复制到当前画布。列表同时收集媒体节点、主体辅助图/声音、时间线内嵌素材，并按类型和来源去重。

复制创建独立节点，保留媒体内容和元数据，不把另一项目的节点 ID 当作当前画布引用。若正在为节点选择参考，复制时同时建立参考连线。复制可撤销，源项目不变。

它仍使用当前浏览器的 IndexedDB；跨设备需导出/导入画布 JSON。账号、对象存储、云同步、多人协作和 AI 服务适配器尚未实现。

## 代码与验证

- `src/canvas/mp4Export.ts`：共同的编码与取消生命周期。
- `src/canvas/timelineRender.ts`：媒体解码、逐帧画面与分块音频混合。
- `src/canvas/stageMotion.ts` / `stageDocument.ts`：动作采样与持久化边界。
- `src/canvas/ProjectAssetLibrary.tsx` / `projectAssets.ts`：项目选择、素材收集与复制。

Mediabunny 固定为 1.62.1（包声明 MPL-2.0）；未修改其源码。实际浏览器和文件验证见 [VALIDATION.md](VALIDATION.md)。
