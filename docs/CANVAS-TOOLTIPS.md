# 工具栏文字与提示对照

2026-10-27。本轮范围是左侧创建工具栏、画布顶部/底部控制、节点标题操作与生成条中的图标按钮。

## 原站依据

- Brave 的独立测试画布实际显示过整列标签：文本、图片、视频、音频、时间线、主体、导演工具箱、导演台、资产库、上传；当时焦点在资产库按钮。不是每个图标各弹一个气泡。原站仍为 4 节点、1 连线，没有提交生成。
- 原站 hover 分支由发布包确认：[`main` 导航壳](../research/canvas/readable/js/545ec3537fff-main.303f6eac20.js#L65178) 中 `revealDetails` 由 hover/focus、dismiss 和焦点恢复状态共同控制。无显示等待计时器；标签透明度与横向位移使用 300ms 动画。展开时整个滚动区域接收指针，避免穿过行间空隙就收起。
- [创建工具栏依赖](../research/canvas/toolbar/readable/1039.525c1475f8.js#L419) 确认使用此导航壳；普通创建项点击收起，资产库只对弹窗恢复焦点特殊处理，工具箱会话期间保持收起。补取的公开脚本原始 URL、字节数和 SHA-256 保存在 [manifest](../research/canvas/toolbar/manifest.json)，原始与格式化版本均保留。
- [顶部和底部控制](../research/canvas/readable/js/9d08566a14ad-canvas-view.c799ffc841.js#L18630) 使用独立 tooltip：顶部延迟 200ms、向下；底部不等待、向上；间距 12px。不要将这些值套给左侧整列标签。
- [快捷键声明](../research/canvas/readable/js/545ec3537fff-main.303f6eac20.js#L63943) 确认文本 T、上传 Cmd/Ctrl+O。原站左侧标签没有快捷键后缀，未给其他创建工具编造快捷键。

原站的独立“纯鼠标进入”分支未通过当前 Brave 原生工具单独验证；运行观察确认了展开外观，hover 规则来自发布包。本地 hover 则已通过实际浏览器指针操作确认。

## 本地修复

- 左侧十个入口一起展开可读名称，标签区域可点击，背景遮罩和位移淡入跟随展开。上下方向键、Home/End、Tab 与 Esc 均可操作；普通创建后的键盘返回重新展开，特殊焦点恢复仅消费一次。
- 工具箱排在导演台前。由于本地工具集合与原站导演工具箱不同，仍使用真实的“媒体工具箱”名称。
- 删除旧 `.cw-rail` 的滚动裁剪规则，滚动由外层统一管理；展开后的行间空隙也属于 hover 区域。窄窗口为上传入口预留与底部撤销条的距离。
- 顶部、底部、撤销/重做、帮助、关闭、节点重命名/选项、堆叠切换、生成/取消、参考与首尾帧交换入口改用同一个提示组件。只允许一个气泡，使用独立浮层避免被节点缩放或父容器裁剪。
- 提示支持鼠标与键盘焦点；已显示和等待期间都能取消。Esc 关闭已显示提示时不会清空画布选区，点击、拖动起手、滚动、失焦不会留下延迟出现的旧提示。禁用按钮仍可用鼠标查看说明。
- 上传 Cmd/Ctrl+O 已实现；支持系统“减少动态效果”。

## 浏览器验收

使用 `localhost:5173` 独立测试项目，与用户 `127.0.0.1` 的项目隔离。

- 鼠标位于左栏、焦点仍在画布时，整列标签展开；从右侧标签经过行间空隙，命中外层滚动区域，标签保持显示。
- 十个入口逐一用方向键访问，标签显示且不创建节点；Home/End 与 Esc 工作正常。点击“图片”文字创建一个节点且收起标签，没有弹出编辑对话框，撤销恢复 5 节点。移到顶部再 Tab 回同一创建按钮，标签再次展开。
- 顶部搜索气泡位于按钮下方，底部抓手气泡位于上方并显示 H；显示气泡时 Esc 只关闭气泡，原选中节点保留。搜索保留键盘焦点、鼠标转到禁用撤销时，只保留“撤销 ⌘ Z”一个气泡。
- 鼠标移入搜索后、气泡尚未显示时按 Esc；随后约 450ms 的 DOM 观察中气泡数量一直为 0。
- Cmd+O 实际触发多文件选择请求，随后取消，没有导入文件。
- 390×600 下上传按钮底部为 484px，撤销条顶部为 502px，互不遮挡；可滚动到最后一项。更多操作气泡右边界 378px，未超出窗口，页面滚动偏移 0。验收后已恢复默认窗口尺寸。

深层图片/时间线/导演台编辑器的所有提示、连线端口原有原生说明、触屏长按与不同操作系统读屏行为不在本轮完整验证范围。没有将这次工具栏修复视为整个原站前端已经完全复刻。
