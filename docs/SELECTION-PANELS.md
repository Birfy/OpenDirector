# 选区与底部面板验收（2026-10-30）

## 原站观察

在已登录的 Brave 中打开[即梦画布](https://jimeng.jianying.com/ai-tool/ai-canvas/8aa20c4e-82fc-47cc-99fe-da7db8e4cf6e)，实际操作抠图与智能改图入口。本轮没有提交原站生成任务。

- 抠图先显示识别中状态及取消按钮，随后在原图显示选区。工具条包含画笔、橡皮、自动主体、快速选择、笔刷尺寸及撤销重做。
- 快速选择可添加或移除图中对象；不需要再创建一个节点来调整选区。
- 智能改图把标记工具条与提示词栏分开。标记包含画笔、箭头、文字、橡皮；底部提示词栏主要容纳描述，模型和生成按钮较紧凑。

## 本地实现

- 使用已有 SAM 3 分割适配器新增临时选区预览接口。识别本身不创建输出素材、任务或节点；首次会复用或上传项目中的来源图片。
- 自动主体、描述、框选返回原尺寸实例蒙版；快速选择按蒙版像素命中并增减实例。画笔、橡皮、撤销重做和清空由本地选区历史管理。取消、关闭或开始手工绘制会中止当前预览请求，晚到响应不能覆盖手工修改。
- 接口采用 [vLLM-Omni 官方分割协议](https://docs.vllm.ai/projects/vllm-omni/en/latest/serving/image_segmentation_api/) 的描述和示例框；对象点击是对返回蒙版的本地操作，不声称支持协议未提供的点提示。
- 抠图确认后按选区保留原像素并生成透明 PNG。没有 SAM 3 时仍可手动选择；自动识别会明确显示未接入。
- 智能改图保留可编辑的标记向量，提交时生成参考图；模型支持多图时同时发送原图与标记图。局部选区以外的像素在结果中保持原图。
- 图片、视频、文本生成框以提示词为主要区域，参数控件压缩到 28 px，生成按钮 32 px，次要操作收入带键盘支持的更多菜单。长提示词最大自动展开至 240 px。
- 同次验收修复了热更新重新载入初始空文档、导入示例项目后旧会话提交报 409，以及全景面板没有读取已连接编辑模型的问题。

## 验证范围

浏览器使用隔离的本地项目目录和模拟分割服务验证：主体自动预览、快速增减、手工画笔、撤销重做、透明抠图结果、清空后重开、智能改图模式切换、提示词与模型选择、更多菜单键盘操作，以及桌面和 390 px 窄屏布局。后端测试覆盖来源归属、参数校验、取消、蒙版透明度、局部改图边界、标记图及指定模型传递。

执行结果：`npm test` 264 项通过；`tests/test_tool_tasks.py` 28 项通过；`npm run build` 通过。生产构建仍有既有的大块体积提示。浏览器另验证了示例导入、刷新保留画布、长文本追加后滚动位置，以及视频编辑面板底部按钮完整显示。

本轮未连接真实 SAM 3 或图片编辑模型进行推理，因此不声明真实模型识别质量、延迟或最终改图效果已经验收。客户端取消会结束本地上游 HTTP 请求，不代表远程 GPU 作业一定停止。
