# 手势与弹窗对照（2026-10-27）

本轮先复现本地问题，再追踪已保存的即梦发布包，并在已登录 Brave 的独立测试项目核对可执行的入口。没有提交生成任务或消耗积分。本地回归使用 `localhost:5173` 的独立项目，不修改用户的 `127.0.0.1` 画布。

## 找到的差异与修复

| 差异 / 缺陷 | 依据 | 当前行为 |
|---|---|---|
| 拖动时生成条立即出现，可能遮住操作区域 | 本地实际复现；原站源码的交互隐藏链见下表 | 按下画布、拖动、缩放节点时隐藏并禁用生成条，保留原组件，松手后按当前单选节点恢复；手动关闭生成条不取消选择，也不会被同节点拖动重开 |
| 普通点击会自动平移/缩放视口 | 本地运行观察；原站单击通用路径只选择 | 单击选择，双击定位；新建时仍确保节点可见 |
| 图片双击打开预览、领域卡片双击打开编辑器 | 本地源码与原站通用双击定位路径不一致 | 普通卡片双击定位；预览、图片编辑、时间线、主体、导演台继续通过明确按钮进入 |
| 快速双击堆叠切换按钮或音视频控件冒泡到编辑入口 | 本地事件链核实，堆叠控件实测 | 父节点激活排除交互控件；移除卡片上的双击弹窗监听 |
| 连接拖动结束以全局 200ms 阻止点击 | 本地源码：可能吞下一次独立点击；起终点接近时又会漏判往返拖动 | 由同一个指针手势记录全过程是否越过 4 屏幕像素，包含往返移动；下一次按下重置，不使用时间窗 |
| 参数按钮上的 Delete 删除背景节点，Escape 抢走子组件关闭逻辑 | 本地事件链核实；修复后真实按键回归 | 参数生成条和领域弹窗拥有自己的按键；画布删除/移动仅在画布区域生效，按钮和输入控件排除；生成导入关闭沿用取消流程 |
| 空白双击新建失效，抓手状态仍走新建逻辑 | 本地实测与 XYFlow 的 pointerup 回调核实 | 读取真正 click 事件的双击计数，选择模式打开菜单，抓手模式忽略；不从 `onPaneClick` 的 pointerup/detail=0 推断双击 |
| 文本节点始终处于输入模式，主体不便拖动 | 原站文本的先选择/再编辑路径；本地实际回归 | 首次点击选择，已选文本再点击、双击或按 Enter 进入编辑；未编辑时整个正文可拖动，Escape 退出并保留选择；一轮文字编辑占一个撤销步骤 |
| 取消手势仍可能接收拖动库的最后一次坐标更新 | 本地取消链检查与历史回归 | Escape、失焦、pointercancel 取消当前移动/缩放事务，忽略已取消手势的迟到位置更新 |

生成条与模态编辑器是不同界面。原站源码支持**拖动中隐藏、结束后恢复生成条**，不能据此声称“拖动结束永远不显示生成条”。

本地保留 XYFlow 的 `nodeDragThreshold=0` 以记录按下时的准确抓取偏移，另在应用的手势边界使用 4 像素点击容差，越过容差前不写入移动/缩放或触发吸附。当前安装库的非零起拖阈值会在首次超过阈值的 move 才取锚点，吸收首段位移；未修改依赖。

Brave 实际检查了空图片选择/双击、生成条和主体资产入口。原站本轮原子拖动没有造成可确认的节点位移，因此拖动中隐藏的结论来自上述完整源码链。未声称捕获了原站拖动过程的每一帧。

## 本地浏览器回归

- 3px 鼠标抖动保持节点坐标不变，不产生撤销步骤；超过阈值后真实移动，单步撤销回到起点。
- 独立图片节点真实移动；DOM 采样捕获拖动时 `visibility:hidden`、`inert`、0 个对话框；松手恢复生成条。单击前后 viewport transform 不变。
- 关闭生成条后选择仍在，继续拖动同节点不重开；有素材图片双击只有定位，明确“编辑图片”按钮仍打开编辑器。
- 堆叠“下一个”连续双击切换两次，没有打开编辑器；时间线卡片双击无弹窗，明确“打开时间线”按钮正常。
- 参数按钮获得焦点后 Delete 保留节点；Escape 只收起参数子面板，生成条仍在。模型设置的按钮上 Delete 保留背景节点，Escape 正常关闭设置。
- 空白双击打开新建菜单；抓手模式同操作不打开；从上传按钮开始拖动没有出现文件选择器。
- 输出端拖到空白后保留曲线与菜单；Escape 取消；直接连到已有节点产生一条边；下一次端口点击正常，一次撤销/重做恢复该连线。
- 文本创建后正文可拖动，没有输入框/弹窗；明确点击后可输入；Escape 退出，一次撤销恢复编辑前文字。

自动回归包含往返拖动、下一次独立点击、拖动后点击不合成双击、4px 容差、抓手/取消、键盘激活、无关指针与取消事务。完整检查结果记于 [VALIDATION.md](VALIDATION.md)。
