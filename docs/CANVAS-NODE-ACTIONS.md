## 实现规则

- 当前动作由项目、源节点、媒体类型、素材 URL 和会话 token 共同确定。切换节点/项目、替换素材或锁定来源会退出失效会话。
- 编辑覆盖在原节点上，不复制一张额外预览卡。专属面板测量后调整视口，可放大源节点，保留原有节点坐标与尺寸；普通节点选择不主动放大。
- 编辑时普通上下栏隐藏；蒙版/裁剪拖动不触发节点拖动，Escape 交给当前面板。参数、已完成笔画和选区保存到来源草稿。
- 显式本地处理与后处理结果导入调用 `appendLinkedMediaResults`，保留来源、追加真实结果和派生关系。普通生成继续使用 `applyGenerationResults` 原位回填。
- 本地图片确认把最后的笔画草稿与输出放在同一个撤销步骤中。后处理文件导入完成时，只有仍处于原会话才切换选择，不打断随后打开的其他工具。
- 首尾帧使用实际媒体 packet 的呈现时间与解码帧，尾帧不再靠固定减去几毫秒猜测。音轨提取按实际解码样本数确定全长。
- 视频延长直接创建空生成节点，保留来源模型/画幅等可用设置，设 5 秒延长提示和源视频引用。它使用当前已有的参考视频生成链；不冒充已接入原站专有延长 API。
- 工具、声音分离、截帧、营销等入口有自己的子菜单；网格上悬停预览尺寸、点击执行，最多 7×7。菜单支持键盘、外点/Escape 关闭和屏幕边缘避让。

## 浏览器验收

在独立 `localhost` 测试文档使用合成的 640×360、2 秒 MP4 与测试 PNG；没有把测试节点加入用户原画布。

| 场景                              | 结果                                                                         |
| --------------------------------- | ---------------------------------------------------------------------------- |
| 图片画笔真实拖动 → 应用本地标记   | 节点不移动、没有弹窗；新增真实带笔画 PNG 与来源边                            |
| 扩图右手柄拖动 → Escape           | 输出宽度从 960 调整为 1143 像素；退出恢复普通操作栏，不新增节点              |
| 多角度选左上 → 向右 5° → 关闭重开 | 水平角 320°、垂直角 30° 保留；没有通用工具目录                               |
| 修剪起点拖动至约 0.432s → 确认    | 原视频保留；得到可播放 640×360、约 1.542s WebM                               |
| 视频画幅设 1:1 → 确认             | 得到真实 360×360 WebM；原视频仍为 640×360                                    |
| 尾帧菜单                          | 直接新增真实 PNG 与来源线                                                    |
| 自定义截帧两次                    | 暂存阶段节点数保持 6；批量确认后一起加入 2 帧                                |
| 2×2 网格切分                      | 生成 4 张实际 320×180 PNG；一次撤销整体移除                                  |
| 视频延长                          | 立即出现空视频草稿、源视频参考、5 秒提示；一次撤销移除                       |
| 800×600                           | 下栏 x=100、y=261、宽680、高261，底部522未越界；内容可滚动，之后恢复默认视口 |

补充实测：后处理文件导入使节点数 9→10，原图 URL 完全不变；一次撤销恢复 9。标注画笔完成后立即确认，结果 9→10，再一次撤销恢复 9。干净页面刷新后完成专属面板操作，控制台 error/warn 均为 0。
